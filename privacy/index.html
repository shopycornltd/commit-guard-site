This privacy notice explains, at a high level, how Shopycorn Ltd handles information related to Commit Guard.

1. Who We Are

Commit Guard is provided by Shopycorn Ltd.

Contact:
Shopycorn Ltd
support@shopycorn.co.uk

2. Information Processed by the Plugin

Depending on how Commit Guard is configured, the plugin may process:

  • source code and file content selected for review
  • commit diffs and staged changes
  • prompts, workflow metadata, and agent handoff data
  • model outputs such as findings, summaries, classifications, and reports
  • local runtime metrics and review telemetry
  • provider configuration data needed to connect to model services

3. Local Processing

Some Commit Guard features can run locally, including local Ollama-based review flows. In these cases, review content may remain on your machine unless you explicitly configure a connected external service or integration.

4. Third-Party Providers and Integrations

If you enable cloud providers or third-party integrations, review content and related metadata may be sent to those external services.

Examples may include:

  • Ollama Cloud
  • OpenAI
  • GitHub services
  • Sonatype Nexus IQ

Those third parties operate under their own terms and privacy policies. Shopycorn Ltd is not responsible for the privacy practices of third-party providers or integrations.

5. Telemetry and Operational Data

Commit Guard may collect and display operational data within the IDE, such as:

  • workflow execution state
  • provider call telemetry
  • token usage summaries
  • daemon health and runtime signals
  • memory-compaction metrics

This data is primarily used to provide product functionality, diagnostics, and review visibility inside the plugin.

6. User Responsibility

You are responsible for deciding:

  • which repositories and files are reviewed
  • which providers or integrations are enabled
  • whether sensitive code or data should be sent to an external model service

7. Data Retention

Commit Guard may persist local review history, workflow snapshots, logs, and configuration data inside the IDE or local application data directories in order to provide history, diagnostics, and workflow continuity.

Retention and removal of such data may depend on local IDE settings, your operating environment, and future product configuration options.

8. Marketplace and Payment Data

JetBrains Marketplace licensing and payment handling are governed by JetBrains Marketplace terms and privacy practices. Shopycorn Ltd does not directly process your JetBrains Marketplace payment details through the plugin.

9. Changes to This Notice

Shopycorn Ltd may update this privacy notice from time to time. The current public version published for Commit Guard will apply to future releases and updates.
